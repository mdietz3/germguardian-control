No key yet? Pairing reads it straight off the purifier.
  1. Press and hold the LINK button FIRST and keep holding it — the purifier only broadcasts its key while the button is down.
  2. Still holding, tap Pair with purifier and pick the device that appears. It has no name; with the Aplix filter it should be the only one.
  3. Registration mode runs on a timer inside the purifier, so the app retries for about 30 seconds. Keep holding until it says paired.
  4. The beacon's rotating token is read and shown. Note this is a per-session challenge, not the key — the key itself is exchanged over a connection we have not yet decoded.
If it doesn't work: tap Show log and send the f011 blob line — that tells us whether the purifier hands over the raw key or a wrapped one.
